Initial release. `JsonStream.DecoderStream` emits the values at selected JSONPath expressions from a JSON stream, and `encodeStream` writes JSON text from a tree of promises, async iterables, and streams. Replaces JSONStream, stream-json, json-stream-stringify, and @worker-tools/json-stream. For NDJSON, use @portable/jsonl.
