# Web platform

These tables list a package for each common task that runs unchanged in browsers, Cloudflare Workers, Node, Bun, and Deno, from Portable or other projects.

For packages from other projects, we check that the main entry point runs in Chromium; in workerd (the Workers runtime) with `nodejs_compat` off; and in Node, Bun, and Deno.

If a task is missing or has a better package, [open an issue](https://github.com/portablejs/portable/issues/new).

## HTTP servers and requests

| Task | Package |
| --- | --- |
| Serve a `fetch` handler with the same code in every server runtime | [srvx](https://www.npmjs.com/package/srvx)<sup>1</sup> |
| Route requests with middleware | [@remix-run/fetch-router](https://www.npmjs.com/package/@remix-run/fetch-router)<sup>1, 2</sup> or [h3](https://www.npmjs.com/package/h3) |
| Match a URL path to a route without a framework | [rou3](https://www.npmjs.com/package/rou3) |
| Call JSON APIs with `fetch`, with retries and an error for a failed status | [ofetch](https://www.npmjs.com/package/ofetch) |
| Parse and format headers such as `Accept`, `Cache-Control`, `Content-Disposition`, and `Range` | [@remix-run/headers](https://www.npmjs.com/package/@remix-run/headers) |
| Sign and verify cookies | [@remix-run/cookie](https://www.npmjs.com/package/@remix-run/cookie) |
| Parse and format `Cookie` and `Set-Cookie` headers | [cookie-es](https://www.npmjs.com/package/cookie-es) |
| Look up a MIME type from a file name | [@remix-run/mime](https://www.npmjs.com/package/@remix-run/mime) |
| Parse `multipart/form-data` uploads as a stream | [@remix-run/multipart-parser](https://www.npmjs.com/package/@remix-run/multipart-parser) or [@remix-run/form-data-parser](https://www.npmjs.com/package/@remix-run/form-data-parser) |
| Serve a file with ETags and `Range` | [@remix-run/response](https://www.npmjs.com/package/@remix-run/response)<sup>3</sup> |
| Stream a large file without reading it into memory | [@remix-run/lazy-file](https://www.npmjs.com/package/@remix-run/lazy-file)<sup>4</sup> |
| Limit request rates | [@portable/rate-limit](/packages/rate-limit) |
| Cache a function's results with a TTL and stale-while-revalidate | [ocache](https://www.npmjs.com/package/ocache) |
| Store keys and values in memory, Workers KV, Redis, and other stores through one API | [unstorage](https://www.npmjs.com/package/unstorage)<sup>5</sup> |
| Verify and sign webhooks | [@portable/webhooks](/packages/webhooks) |
| Sign requests to AWS or S3-compatible storage such as Cloudflare R2 | [aws4fetch](https://www.npmjs.com/package/aws4fetch) |
| Call gRPC and Connect services | [@connectrpc/connect](https://www.npmjs.com/package/@connectrpc/connect) |

<sup>1</sup> To serve fetch-router, pass `router.fetch` to srvx's `serve`, `Bun.serve`, or `Deno.serve`, or use it as a Worker's `fetch` handler. srvx uses each runtime's own server. On Node, it converts Node's request and response objects to `Request` and `Response`.


<sup>2</sup> The @remix-run packages come from Remix 3. The remix package re-exports each one under a subpath, such as `remix/headers`.

<sup>3</sup> The `@remix-run/response/compress` subpath imports `node:zlib`, so it doesn't run in browsers or in Workers without `nodejs_compat`.

<sup>4</sup> To serve a large file, pass a `LazyFile` to `createFileResponse` from `@remix-run/response/file`.

<sup>5</sup> Some unstorage drivers, such as `unstorage/drivers/fs`, import `node:*` modules, so they don't run in browsers or in Workers without `nodejs_compat`.
