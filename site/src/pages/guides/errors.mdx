# Errors

Package errors subclass the classes in [errors](/packages/errors), so one check works for errors from any package:

| Class | Thrown when |
| --- | --- |
| `InvalidInputError` | The data is malformed. |
| `TruncatedError` | The input ended before a value was complete. |
| `UnsupportedError` | The input is valid, but the package doesn't handle it. |
| `MaxBytesError`, `MaxLengthError` | The input or output exceeded the `maxBytes` or `maxLength` option. |
| `ResponseError` | A server returned a status or body the package can't use. |

For a missing argument or one with the wrong type, functions throw the built-in `TypeError`. For a value they don't accept, they throw `RangeError`. These mean the calling code has a bug, so don't catch them.

## Check the kind with `Errors.is`

`Errors.is(error, kind)` checks an error's kind and narrows its type, so you can read its fields. The kind is the class name without `Error`: `'InvalidInput'`, `'Truncated'`, `'Unsupported'`, `'MaxBytes'`, `'MaxLength'`, or `'Response'`.

In this Worker, `Streams.limitBytes` and `Compress.decode` each throw their own `MaxBytesError`, and one check handles both:

```ts
import * as Compress from '@portable/compress';
import * as Errors from '@portable/errors';
import * as Streams from '@portable/streams';

export default {
  async fetch(request: Request) {
    try {
      const body = await Streams.toBytes(
        request.body!.pipeThrough(Streams.limitBytes(1_000_000)),
      );
      const data = await Compress.decode(body, {
        maxBytes: 10_000_000,
      });
      return Response.json({ bytes: data.length });
    } catch (error) {
      if (Errors.is(error, 'MaxBytes')) {
        return new Response(`Over ${error.maxBytes} bytes`, {
          status: 413,
        });
      }
      if (
        Errors.is(error, 'InvalidInput') ||
        Errors.is(error, 'Truncated')
      ) {
        return new Response('Bad gzip data', { status: 400 });
      }
      throw error;
    }
  },
};
```

To match only one package's error, use `instanceof`, such as `error instanceof Compress.MaxBytesError`.

Each error's `name` starts with its package namespace, such as `'Compress.MaxBytesError'`, so logs show which package threw it.

## Read the server's response

A `ResponseError` has the HTTP `status`, and the whole `Response` in `response`, so you can read its headers:

```ts
import * as Errors from '@portable/errors';
import * as Rdap from '@portable/rdap';

try {
  await Rdap.domain('example.com');
} catch (error) {
  if (Errors.is(error, 'Response') && error.status === 429) {
    const seconds = Number(error.response.headers.get('retry-after'));
    console.log(`Rate limited, retry in ${seconds} seconds`);
  } else {
    throw error;
  }
}
```

If the package read the body, `body` holds it as parsed JSON or text.

## Find the original error

When a package throws its own error in place of a platform error, the original is in `cause`. For example, when `DecompressionStream` rejects malformed data, `Compress.decode` throws an `InvalidInputError` whose `cause` is the stream's error (a `TypeError` in Node):

```ts
import * as Compress from '@portable/compress';
import * as Errors from '@portable/errors';

try {
  await Compress.decode(body);
} catch (error) {
  if (Errors.is(error, 'InvalidInput')) {
    console.log(error.cause);
  }
}
```

## Match errors across two copies of a package

`Errors.is` and `instanceof` both work when your app has two copies of a package, such as version 1 and version 2. Portable packages depend on each other at exact versions, so two copies are more common than with most libraries.

Both checks read the error's kinds from `Symbol.for('portable.error')`, which is the same in every copy.


## Throw your own errors

Extend the same classes so one check handles your errors and Portable's. `kind` sets the error's `name`:


```ts
import * as Errors from '@portable/errors';

class UploadTooLargeError extends Errors.MaxBytesError {
  static override readonly kind: string = 'MyApp.UploadTooLargeError';
}

const error = new UploadTooLargeError({ maxBytes: 1_000_000 });
error.name; // 'MyApp.UploadTooLargeError'
Errors.is(error, 'MaxBytes'); // true
```
