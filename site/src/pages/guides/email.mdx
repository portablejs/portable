# Email

Each step of sending or receiving email is a separate package. The packages pass messages to each other as `ReadableStream<Uint8Array>`, and none of them copies an attachment into memory.

Sending:

- [`mail`](/packages/mail) builds a raw message with attachments and inline images.
- [`dkim`](/packages/dkim) signs it.
- [`smtp`](/packages/smtp) sends it from any runtime with a TCP socket API.

Receiving:

- [`mail-auth`](/packages/mail-auth) checks SPF, DKIM, DMARC, and ARC in one call. [`spf`](/packages/spf), [`dkim`](/packages/dkim), [`dmarc`](/packages/dmarc), and [`arc`](/packages/arc) do each check on its own.
- [`mime-stream`](/packages/mime-stream) splits a message into its parts.
- [`mime-headers`](/packages/mime-headers) decodes encoded words and address lists.

[`quoted-printable`](/packages/quoted-printable), [`base64`](/packages/base64), and [`charset`](/packages/charset) handle the body encodings.

## Send a signed message from a Worker

```ts
import * as Dkim from '@portable/dkim'
import * as Mail from '@portable/mail'
import * as Smtp from '@portable/smtp'
import * as Streams from '@portable/streams'
import { connect } from 'cloudflare:sockets'

const message: Mail.Message = {
  from: 'Ada <ada@example.com>',
  to: 'grace@example.org',
  subject: 'Report',
  text: 'The report is attached.',
  attachments: [
    { content: (await fetch(reportUrl)).body!, filename: 'report.pdf' },
  ],
}

const [forSigning, forSending] = Mail.encodeStream(message).tee()
const field = await Dkim.sign(forSigning, {
  domain: 'example.com',
  selector: 'mail',
  privateKey: env.DKIM_KEY,
})

await Smtp.send(
  {
    ...Mail.envelope(message),
    message: Streams.concat([
      [new TextEncoder().encode(field)],
      forSending,
    ]),
  },
  {
    connect,
    host: 'smtp.example.com',
    port: 587,
    auth: { user: 'ada@example.com', pass: env.SMTP_PASSWORD },
  },
)
```

`Dkim.sign` must read the whole message before it returns, because the DKIM-Signature field goes before the message and contains a hash of the body. `tee` splits the stream into two, and the second copy is sent after the signature field.
