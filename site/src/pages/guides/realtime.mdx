# Realtime

A long-lived connection can drop and has to reconnect. A slow reader also must not force the sender to buffer without limit. These packages give you each connection as a `ReadableStream` and a `WritableStream`. Backpressure and cancellation then work as they do for a `fetch` body.

- [`websockets`](/packages/websockets) is a WebSocket that reconnects, read and written as streams.
- [`sse`](/packages/sse) reads and writes server-sent event streams.
- [`rpc`](/packages/rpc) makes typed JSON-RPC calls between workers, windows, servers, and browsers.
- [`web-push`](/packages/web-push) sends notifications to a browser that isn't open.

## Stream a model's output to the browser

This Worker reads a server-sent event stream from an API. It forwards only the text of each event, as a new event stream:

```ts
import * as Sse from '@portable/sse'
import * as Streams from '@portable/streams'

export default {
  async fetch(request: Request) {
    const upstream = await fetch('https://api.example.com/v1/chat', {
      method: 'POST',
      body: await request.text(),
      signal: request.signal,
    })
    const body = upstream
      .body!.pipeThrough(new Sse.DecoderStream())
      .pipeThrough(
        Streams.map((event) => ({ data: JSON.parse(event.data).text })),
      )
      .pipeThrough(new Sse.EncoderStream())
    return new Response(body, {
      headers: { 'content-type': 'text/event-stream' },
    })
  },
}
```
