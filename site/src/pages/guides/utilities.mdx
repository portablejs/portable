# Utilities

- [bytes](/packages/bytes) converts `Uint8Array`s to and from hex, joins them, and compares them, with `timingSafeEqual` for secrets.
- [errors](/packages/errors) has the error classes every package throws, and `Errors.is` to check an error's kind. See the [errors guide](/guides/errors).
- [random](/packages/random) gives unbiased random integers, strings, and shuffles from `crypto.getRandomValues`, and a seeded generator for tests.

## Check a signature in constant time

Compare secrets with `Bytes.timingSafeEqual`. An ordinary comparison returns at the first differing byte, so its timing shows how much of a signature an attacker guessed right.


```ts
import * as Bytes from '@portable/bytes';

const expected = new Uint8Array(
  await crypto.subtle.sign('HMAC', key, payload),
);
if (!Bytes.timingSafeEqual(expected, Bytes.fromHex(signature))) {
  throw new Error('Bad signature');
}
```
