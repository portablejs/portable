How it works

This page has no server. It reads Bluesky's public Jetstream WebSocket, which sends every new post as JSON, with two Portable packages: @portable/websockets and @portable/streams. The same code runs in browsers, Cloudflare Workers, Node 24+, Bun, and Deno.

Subscribe from a cursor

Every event has a time_us cursor. WebSockets.connect calls the URL function before every attempt, so a dropped connection resumes from the last post seen instead of skipping what was posted in between. 

import * as Streams from '@portable/streams';
import * as WebSockets from '@portable/websockets';

let cursor: number | undefined;

function jetstream(from?: number): URL {
  const url = new URL('wss://jetstream2.us-east.bsky.network/subscribe');
  url.searchParams.set('wantedCollections', 'app.bsky.feed.post');
  if (from) {
    url.searchParams.set('cursor', String(from));
  }
  return url;
}

function subscribe(signal?: AbortSignal): ReadableStream<string | Uint8Array> {
  return WebSockets.connect(() => jetstream(cursor), { signal }).readable;
}

Pipe messages into posts

The socket's readable is a web ReadableStream, so it pipes through transforms like any other stream. Streams.toAsyncIterable loops over it in every runtime, including browsers that can't iterate a stream with for await yet. 

const posts = subscribe()
  .pipeThrough(Streams.map((message) => JSON.parse(message as string)))
  .pipeThrough(Streams.tap((event) => {
    cursor = event.time_us;
  }))
  .pipeThrough(Streams.filter((event) => event.commit?.operation === 'create'));

for await (const event of Streams.toAsyncIterable(posts)) {
  draw(columnFor(event), event);
}

Pause a column, then catch up from its cursor

Hovering a column saves the cursor and drops that column's new posts, so the page buffers nothing. Leaving it opens a second socket at the saved cursor. Jetstream replays from there, the page keeps that column's language, and the socket closes once it reaches the cursor where the column resumed. The main socket never stops. Jetstream keeps about a day and a half of posts. 

async function catchUp(column: Column, from: number, until: number) {
  const controller = new AbortController();
  const replay = WebSockets.connect(jetstream(from), { signal: controller.signal }).readable
    .pipeThrough(Streams.map((message) => JSON.parse(message as string)));

  for await (const event of Streams.toAsyncIterable(replay)) {
    if (event.time_us > until) {
      break;
    }
    if (columnFor(event) === column) {
      draw(column, event);
    }
  }
  controller.abort(); // closes the catch-up socket
}

Run it anywhere

Apart from the canvas, nothing here uses a browser API, so subscribe and catchUp work unchanged in a Cloudflare Worker or Durable Object that counts posts per language, or in a command-line tool on Node, Bun, or Deno. 

npm install @portable/websockets @portable/streams
